# Frontend Routing Engine — Zesty Application

Zesty uses state-based single-page view routing in `App.jsx`.

---

## 🗺️ State Views & Access Matrix

- `feed` — Main food discovery feed (Customer / Guest).
- `reels` — Vertical video reels feed (Customer / Guest).
- `studio` — Partner Studio Dashboard (Restricted: `foodpartner`).
- `delivery` — Delivery Rider Workspace (Restricted: `delivery`).
- `admin` — Super Admin Control Panel (Restricted: `admin`).
- `orders` — Customer active order history (Restricted: `user`).
- `cart` — Customer shopping cart view (Customer / Guest).
